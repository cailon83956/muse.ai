# cookies.txt

## Cach lay (tren may tinh)
1. Dang nhap YouTube / Facebook tren Chrome.
2. Cai extension "Get cookies.txt LOCALLY", bam Export -> luu `cookies.txt`.
3. Tren Discord, go lenh `/cookies` va dinh kem file `cookies.txt` vua xuat.
   Bot chi luu file o day (chmod 0600), khong hien gia tri cookie ra chat.

## Luu y
- Cookie = phien dang nhap, ai co file nay thi vao duoc tai khoan cua may — chi gui
  cho bot cua may, dung gui lung tung. Het han / doi mat khau thi phai xuat lai.
- Khong commit file nay len git (da co trong .gitignore).
- Khong co file nay thi bot van tai duoc video cong khai.
- Kiem tra: `/cookies-status`. Xoa: `/cookies-clear`.
